## Marchand Studio

The all-in-one desktop AI studio: chat, code agent, pictures, and training your own local AI with Claude, Grok or any model.

**Download `MarchandStudio-Setup.exe` below**, run it, accept the license and press Install. No administrator rights needed. Python is included.

- **Fixed:** Claude no longer hangs when you attach large files or folders. New: live grey activity feed, message queue with Send now, AMD support, "My AI" category, drag-and-drop for folders.
- Windows SmartScreen may warn because the installer is not code-signed: choose **More info**, then **Run anyway**.
- Optional: install Ollama (ollama.com) for local models and Claude Code (claude.ai/code) to use your Claude subscription.
