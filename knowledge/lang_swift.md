# Swift
- Build/test with `swift build` / `swift test` or Xcode. Use `let` over `var`, optionals (`if let`, `guard let`, `??`), never force-unwrap (`!`) without proof.
- Value types (struct/enum) by default; protocols for abstraction; `Codable` for JSON; `Result` and `throws` for errors; `async/await` and actors for concurrency.
